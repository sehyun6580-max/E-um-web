## 5. 대화 컨트롤러 (지금 규칙)

`prompts.ts`의 규칙 문서는 **원칙·컨트롤러·안전 → 모드 → 고민 종류 → 캐릭터 → 현재 단계** 순서로 쌓여요. 캐릭터는 말투만 바꾸고 원칙이 항상 우선이에요. 단계는 코드가 정하고(사용자 발화 1~2번째 탐색, 3~5번째 정리, 6번째부터 마무리), **어떤 컨트롤러를 쓸지는 모델이 규칙 문서를 읽고 판단해요.** 어떤 규칙이 작동했는지는 기록에 남지 않아요.

| 순위 | 규칙 | 이럴 때 (Trigger) | 이렇게 (Required Move) | 하지 않음 (Prohibited Move) |
| --- | --- | --- | --- | --- |
| 최우선 | 안전: 자해·자살 | 죽고 싶다, 사라지고 싶다 | 역할을 내려놓고 109 안내, 위험하면 112·119 | 분석, 다른 시선 질문 |
| 최우선 | 안전: 폭력·위협 | 맞음, 협박, 감시, 스토킹, 성적 강요 | 112·1366 안내 | 화해·참기 권유 |
| Tier 1 | 판단 외주화 제어 | "그냥 헤어질까?", "네가 정해 줘" | 그 결정에 필요한 사용자의 기준을 되물음 | 결론, **다음 행동 지시**(PR #6) |
| Tier 2 | 시코팬시 방지 | "내 말 맞지?", 일방적 비난 | 감정은 인정, 사실 판단은 보류 | 함께 비난, 추측을 사실로 |
| Tier 2 | 정보 부족 제어 | 핵심 정보가 빠짐 | 꼭 필요한 정보 하나만 물음 | 추측으로 메우기 |
| Tier 2 | 과도한 일반화 제어 | "맨날", "항상" | 단정과 실제 사건을 나눔 | 단정 따라가기 |
| Tier 3 | 관점 전환·조건 변경 | 모호한 감정 표현 | 조건을 바꿔 보는 가정 | 맥락 없는 질문 |
| Tier 3 | 모드 침범·이탈 제어 | 같은 호소 반복 / 팩폭에서 상처·위로 요구 | 기준을 물음 / 감정 인정, **공감 모드 안내**(PR #6) | 같은 위로 반복, 무조건 동의 |

항상 적용: 질문 절제, **기준은 사용자의 말로**(PR #7: "핵심은 ~야" 단정 금지, 보기는 필요할 때만·보기 밖 답 열어 두기, 정리 단계에서 사용자의 말로 기준 확인받기), 마무리 감지, 말투 맞추기, 세 태그 출력.

두 모드는 말투가 아니라 **탐색 대상**이 달라요. 공감 모드(F, Claude)는 내면("나는 왜 서운한가"), 팩폭 모드(T, GPT)는 외부("조건을 바꾸면 어떤가"). 아첨 방지와 결정권 반환은 공통이에요.


## 11. 결정 기록 (왜 이렇게 만들었나)

- **Streamlit → Next.js**: GitHub·Vercel 배포를 위해. Vercel은 Python 서버를 계속 띄울 수 없어요.
- **F는 Claude, T는 OpenAI**: 기능설명서 구성 그대로. Claude는 짧은 답이라 `effort: low`.
- **태그 출력**: 제목·본문·다른 시선을 스트리밍 중에도 안정적으로 나누려고.
- **데모 로그인·브라우저 저장**: 서버 DB 없이 바로 시연하려고. 실제 서비스면 8장 9번.
- **키 없이도 동작**: 키 없이 화면 작업을 할 수 있게 예시 답변 모드.
- **캐릭터는 말투만**: 원칙·안전은 캐릭터와 상관없이 같아야 해서 캐릭터 문단을 원칙 뒤에 두고 "원칙이 우선". 연인 역할은 의존 위험으로 막음.
- **화해 편지는 링크로**: 서버 없이 주고받고, 민감한 내용이 서버에 남지 않게.
- **모드를 말투가 아니라 탐색 대상으로 구분** (중간시연 피드백 7): 공감이 훈계처럼, 팩폭이 비난처럼 들리는 회색 지대를 줄이려고.
- **규칙에 우선순위(Tier)** (피드백 9): 여러 규칙이 동시에 걸릴 때 판단 외주화 → 사실 왜곡 → 사고 확장 순. 그 위에 안전 2개.
- **투명성 배지를 화면에 넣지 않음** (피드백 6-②): 상담이 심사처럼 느껴질 수 있어서. 대가로 규칙 추적이 어려워요 (8장 4번).
- **행동 지시도 결론으로 봄** (PR #6), **기준은 사용자의 말로** (PR #7): 결정권을 돌려줘도 무엇이 기준인지 AI가 정하면 사용자는 AI의 틀 안에서 고르기만 하게 돼요. "AI는 기준의 재료(사실·조건·질문)를 건네고, 기준의 문장은 사용자가 쓴다."
